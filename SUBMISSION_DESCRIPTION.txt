BountyMatchRouter: a skill-matching escrow, not a duplicate-detection gate. A poster deposits a reward against a plain-text requirement; workers self-register a free-text skill summary into a pool. find_and_judge deterministically ranks the pool by embedding similarity (zero nondet cost), then asks validators one prompt_comparative round whether the closest untried candidate's stated skills genuinely fit the requirement, never a bare similarity threshold. Only FIT proposes a match; escrow pays on confirmation, refunds on cancellation or timeout, never stranded. Distinct from this repo's embeddings-dedup sibling: embeddings rank a whole pool for a judged fit, not pre-filter near-duplicate pairs. Building the harness surfaced two real bugs, a missing .view() call in the example and a gltest factory path issue, both fixed via a live consensus run before hitting StudioNet's hourly limit. 49/49 direct-mode adversarial tests pass; lint clean on the primitive and worked example.
